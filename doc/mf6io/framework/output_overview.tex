\mf~can produce a large number of output files.  The options that control this output are distributed across the Output Control (OC) Package, the model name file, individual package input files, and the solution input files.  Each of these is described where it is defined; this section summarizes how they work together.

\subsection{Types of Output}

\mf~output falls into the following general categories.

\begin{itemize}
\item \textbf{Listing files.}  The simulation listing file (mfsim.lst) and a listing file for each model.  Model listing files contain printed tables of dependent variables, volumetric budgets, and, optionally, package input and simulated flows.
\item \textbf{Binary dependent-variable files.}  Head (GWF), concentration (GWT), or temperature (GWE) for each model cell, and analogous quantities for advanced packages (for example, lake and stream stage, well head, unsaturated-zone water content, and lake or stream concentration and temperature).
\item \textbf{Binary budget files.}  Cell-by-cell flows for a model, and package-specific flows for advanced packages.
\item \textbf{Comma-separated value (CSV) files.}  Time series of model or package budget totals, observations, solver convergence information, and particle tracks.
\end{itemize}

The binary file formats are described in the section ``Description of Binary Output Files.''

\subsection{Print, Save, and CSV Output}

Most output in \mf~is governed by two levels of control:

\begin{enumerate}
\item A \textbf{package-level} (or model-level) option that determines \emph{what} may be written---for example, the SAVE\_FLOWS and PRINT\_FLOWS options, or a FILEOUT record that names a package output file.
\item The \textbf{Output Control} PERIOD block settings, SAVE and PRINT, that determine \emph{when} that output is written, on a time step basis.
\end{enumerate}

\noindent Output that is subject to Output Control is written only for time steps in which both conditions are satisfied.  For example, cell-by-cell flows for the Well Package are written to the model budget file only if SAVE\_FLOWS is specified for the Well Package (or for the model, see below) \emph{and} Output Control specifies SAVE BUDGET for the current time step.  Specifying SAVE\_FLOWS in a package without also specifying a BUDGET FILEOUT record and SAVE BUDGET in Output Control results in no saved flows for that package.

CSV output files generally are \emph{not} subject to Output Control.  Once a CSV output file is requested, it is written every time step (or, for solver output, every iteration), regardless of the SAVE and PRINT settings in the Output Control PERIOD blocks.

\subsection{Additional Notes}

\begin{itemize}
\item \textbf{Model-level flags.}  The SAVE\_FLOWS, PRINT\_FLOWS, and PRINT\_INPUT options in a model name file act as defaults for every package in the model.  A package option can enable output that is not enabled at the model level, but cannot disable output that is enabled at the model level.

\item \textbf{Printing is forced at the end of each stress period.}  Regardless of the PRINT settings in Output Control, budget and dependent-variable tables (including PRINT\_FLOWS package tables) are written to the model listing file for the last time step of every stress period.  These tables are also written for any time step that fails to converge, unless the simulation is run with the CONTINUE option.  No corresponding override exists for SAVE; binary files are written only for time steps selected by Output Control.

\item \textbf{Package budget files do not require SAVE\_FLOWS.}  Advanced package budget files (for example, the SFR Package BUDGET FILEOUT file) are controlled by the FILEOUT record in the package and the OC SAVE BUDGET setting; the SAVE\_FLOWS option affects only whether the package's flows to and from model cells are written to the model budget file.

\item \textbf{Advanced package dependent-variable files follow OC SAVE HEAD.}  Stage, head, water content, concentration, and temperature files for advanced packages are written for the time steps on which the model's dependent variable is saved, not the time steps on which budgets are saved.

\item \textbf{Default Output Control.}  If no OC file is specified, budget and dependent-variable tables are printed to the model listing file at the end of each stress period, and no binary dependent-variable or budget files are written.

\item \textbf{Output Control settings persist.}  SAVE and PRINT settings in an Output Control PERIOD block remain in effect for subsequent stress periods until another PERIOD block is specified.  An empty PERIOD block turns off all SAVE and PRINT output for that and subsequent stress periods.
\end{itemize}
