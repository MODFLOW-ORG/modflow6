Input to the Time-Varying Hydraulic Conductivity with Grid Array Input (TVKG) Utility is read from the file that is specified in the TVKG6 record of the OPTIONS block in the NPF package.  TVKG provides the same changes to hydraulic conductivity as the TVK Utility, with values specified as arrays for the model grid rather than as a list of cells.  TVK6 and TVKG6 cannot both be specified.
