Input to the Variably Saturated Flow (VSF) Package is read from the file that has type ``VSF6'' in the Name File.  A single VSF Package can be activated in a GWF model.  When the VSF Package is present, the model solves the variably saturated (Richards) form of the groundwater flow equation, so that unsaturated flow and storage above the water table are represented; the VSF Package must also be active for the VSET, VSSB, and VSSP Packages to be used.

The cells in which the Richards formulation is applied are flagged by the IVARSAT array in the GRIDDATA block.  The VSF formulation must be applied to the entire active domain: IVARSAT must be set for every active cell, and applying Richards flow to only part of the domain is not supported.  Because the unsaturated formulation supersedes the convertible-cell logic of the Node Property Flow (NPF) Package, every VSF cell must be a non-convertible cell (ICELLTYPE equal to zero in NPF).

The functions that relate pressure head, water saturation, moisture capacity, and relative permeability are selected with the SOIL\_MODEL option (Brooks-Corey, Haverkamp, or Van Genuchten).  The soil-property arrays that must be supplied in the GRIDDATA block depend on the selected model; the arrays that do not apply to the chosen model are omitted.  Simulated water saturation and pressure head can be written to separate binary output files whenever heads are written to the binary head file, as controlled by the Output Control (OC) Package.

With the Newton-Raphson formulation, the head change of an outer iteration is scaled back in cells where it would change the effective saturation by more than NEWTON\_DSAT\_MAX (0.2 by default).  This helps wetting fronts advance into dry soil, where full Newton steps tend to overshoot.  The scaling is proportional, so the limit is approximate; it changes the iteration path but not the converged solution, and a value of zero switches it off.

For the Van Genuchten model with $n < 2$, the relative permeability has an infinite slope at saturation, which can make the Newton iteration oscillate in fine-grained soils close to saturation.  Two optional remedies are available.  KR\_SMOOTHING replaces the relative permeability between the specified pressure head below saturation and saturation by a smooth cubic curve; the retention curve is not changed.  The smoothing width is a length in model units (2~cm worked well for the soils tested), and smoothing is off by default because it slightly changes the solution.  HAEVGN specifies an air-entry pressure head per cell (Vogel and others, 2001): the soil is saturated for pressure heads above this value and the saturation and relative permeability curves are rescaled accordingly.  HAEVGN changes the soil description itself and is therefore a modeling choice rather than a numerical setting.
